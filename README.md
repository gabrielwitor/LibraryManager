# Library Manager

This repository contains a very basic ASP.NET Web API created following the repository pattern. 
Upon running the project, a web browser tab will automatically open. In this tab it is possible to test the endpoints (swagger). You can also visualize the book schema and see what are the possible results when calling each endpoint.

To run this project, you first have to clone it.

```bash
git clone https://github.com/gabrielwitor/LibraryManager
```
Now, open the project using Visual Studio and press 'F5'. You now should have the project up and running.
